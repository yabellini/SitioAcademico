It is a three-hour course on how to use Git and GitHub to collaboratively develop open-source software with the R language. It was organized for the Champions program of rOpenSci. Content: Create a GitHub account, create repos, branches, clone and fork, commit, Pull and Push, Pull Request, Review of Pull Request, Merge.
